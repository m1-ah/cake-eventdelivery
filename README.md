# 🎂 Cake Event Delivery App

The Cake Event Delivery App is a web-based platform designed to streamline the process of ordering and delivering cakes for various events. Whether it's a birthday, wedding, or corporate event, users can browse through a selection of cakes, place orders, and have them delivered to their desired location.

## 🚀 Features

- **User Registration & Authentication**: Secure sign-up and login functionality for users.
- **Cake Catalog**: Browse through a variety of cakes with images, descriptions, and prices.
- **Shopping Cart**: Add cakes to the cart and manage orders before checkout.
- **Order Management**: Users can view their order history and track current orders.
- **Admin Panel**: Manage cake listings, view orders, and handle user queries.
- **Responsive Design**: Optimized for both desktop and mobile devices.

## 🛠️ Technologies Used

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP
- **Database**: MySQL
- **Version Control**: Git

## 🧑‍💻 Getting Started

### Prerequisites

- PHP installed on your local machine
- MySQL database
- Web server (e.g., Apache)

### Installation

1. **Clone the repository**:
   git clone https://github.com/m1-ah/cake-eventdelivery.git
   cd cake-eventdelivery

2. **Set up the database**:
Import the cake_eventdelivery.sql file located in the sql/ directory into your MySQL server.

3. **Configure the database connection**:
Update the database credentials in the config.php file.

4. **Run the application**:
Start your web server and navigate to http://localhost/cake-eventdelivery in your browser.
